# 复制下面这一行命令，在服务器上运行：

cd /var/www/approval-viewer/approvalquery && ls -lh approval_data.json index.html && curl -I http://localhost/approvalquery/approval_data.json

# 如果看到 HTTP/1.1 200 OK，说明文件可以访问
# 如果看到 404，说明nginx配置有问题

# 然后运行这个看看nginx配置：
cat /etc/nginx/sites-available/approval-viewer | grep -A 10 "location /approvalquery"

# 最可能的问题：nginx配置的alias路径不对
# 应该是：alias /var/www/approval-viewer/approvalquery;
# 而不是：alias /var/www/approval-viewer;
